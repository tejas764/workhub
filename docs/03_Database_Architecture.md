# Overview

Indexes improve query performance by allowing PostgreSQL to locate rows without scanning entire tables.

The WorkHub AI database uses two types of indexes:

- B-Tree Indexes
- IVFFlat Vector Index

---

# B-Tree Indexes

B-Tree indexes are used for:

- Filtering
- Sorting
- Foreign Keys
- Equality searches
- Range searches

# IVFFlat Index

The embeddings table stores vector representations generated by the embedding model.

```
VECTOR(768)
```

Similarity search uses cosine distance.

```sql
USING ivfflat
```

This allows PostgreSQL to perform approximate nearest-neighbor search instead of scanning every vector.
